# 👨‍💻 Sobre mim

Sou **Elias Ribeiro**, Desenvolvedor Front-End apaixonado por criar interfaces modernas, responsivas e acessíveis.

Minha jornada na programação começou de forma inusitada. Durante minha atuação como **Eletricista Automotivo**, precisei desenvolver uma ferramenta própria para facilitar diagnósticos eletrônicos utilizando **Arduino** e **C++**.

Foi nesse momento que descobri minha paixão pelo desenvolvimento de software.

Hoje aplico essa experiência em lógica, resolução de problemas e tecnologia para desenvolver aplicações web modernas utilizando React, TypeScript e outras tecnologias do ecossistema Front-End.
